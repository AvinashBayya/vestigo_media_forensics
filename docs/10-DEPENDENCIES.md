- Python 3.11
- FastAPI
- Uvicorn
- Pydantic
- SQLAlchemy
- SQLite
- Pillow
- ExifTool
- Tesseract OCR
- imagehash
- pytest
- httpx

## Frontend — Milestone 1

- React
- Vite
- TypeScript
- Axios or fetch
- Minimal UI library or plain CSS

## Container tools

- Docker
- Docker Compose
- Dev Containers
- Git

## Installed but not used in Milestone 1

- FFmpeg

These are installed and verified during environment setup. They will be used in Milestone 3 for video metadata, keyframe extraction, and scene detection.
